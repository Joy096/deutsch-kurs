**Словарь — WBDATA**: `{art, de, pl, ru, tema}`
Темы: `Kursraum, Alltag, Möbel, Bad, Wohnung, Familie, Adjektive, Phrase`
**Названия тем брать из названий разделов учебника.**
При добавлении новой темы — добавить её также в массив `TEMEN` внутри компонента словаря.
Существительные: `art:"der/die/das"`. Прилагательные/глаголы/фразы/наречия: `art:"", pl:"—"`.
Слова только во мн.ч. (Eltern, Geschwister, Großeltern и т.п.): `pl:"—"` — прочерк сигнализирует что слово изначально множественное.
Антонимы прилагательных — в `ADJEKTIV_PAARE`: `{a, ra, b, rb}` (a = основное, b = антоним, скрыт, отображается как ≠ a).
Оценочные слова — в `BEWERTUNG`.
**Новые слова добавлять в конец WBDATA** — иначе не попадут в плоский список «Все → Все» (новые сначала).
Профессии с женской формой — поле `ru` через `\n`: `"учитель\nf. - die Lehrerin"` — отображается в две строки.
**Слова в словарь не добавлять автоматически** — только по явной просьбе.

**Диалоги — DIALOGE** (не DIALOG_FRAGEN): структура `{L1:[...], L2:[...], L3:[...], L4:[...]}`.
Каждый урок содержит ровно **две группы**:
- `{tag:"Основные", ...}` — только вопросы/фразы с Kommunikation-страницы учебника (последняя страница раздела)
- `{tag:"Дополнительные", ...}` — принципиально разные, из других страниц; не дублировать то, что уже есть в предыдущих уроках

Каждая пара: `{q, a, note, fm?}`
- `fm:"f"` — только Formell (Sie), `fm:"i"` — только Informell (du), без `fm` — оба режима
- Formell/Informell тогл — только для L1
- Вопросы (q с `?`) → вкладка «Вопросы». Фразы (без `?`) → вкладка «Фразы» (плоский список без групп)
- Не добавлять похожие вопросы если такой уже есть в предыдущем уроке

**LEKTIONEN**: названия секций брать из учебника (например `"D · Eine Wohnung suchen"`). Проверять существующие `id` перед добавлением.
Задания (`ex:`) — только к секциям с теорией (`hasT:true`). Не добавлять придуманные отдельные упражнения (Karteikarten, Artikel-Trainer и т.п.) как самостоятельные секции.
**Großer Test** каждого урока содержит несколько типов заданий через `GrosserTestContainer`: Quiz, LueckenQuiz, Zuordnung, WortstellungGame. При добавлении нового типа — добавлять `key={round}` на враппер контента чтобы сбрасывать состояние при переключении.
